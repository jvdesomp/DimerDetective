overview

DimerDetective predicts primer dimer formation from the 3′ end stability of every primer combination. Primer dimers form when the 3′ end of one primer hybridizes to another primer (or to itself), leading to spurious amplification products and lower PCR efficiency. A more negative ΔG means a more stable dimer and a higher risk.

Everything runs in your browser: your sequences are never sent to a server. Pair mode analyzes defined primer pairs; multiplex mode tests every primer in a set against every other primer.

thermodynamic model

Free energies are computed with the calc_end_stability function of primer3 (Untergasser et al. 2012): the thal dynamic programming algorithm in alignment mode END1, with Watson–Crick nearest-neighbor stacks, mismatch stacks, dangling ends, internal loops and bulge loops. The C source of thal and its parameter files are taken unchanged from primer3-py 2.4.0 and compiled to WebAssembly, so the web app and the Python script run the same code and give identical ΔG values. The alignment shown is the structure found in that same computation.

Nearest-neighbor parameters follow SantaLucia (1998).

salt correction

ΔScorrected = ΔS + 0.368 × (N − 1) × ln(([Na+] + 120 × √[free Mg2+]) / 1000), with concentrations in mM, N the number of base pairs in the duplex and [free Mg2+] = max(0, [Mg2+] − [dNTP]).

scoring metrics

For each primer pair, six 3′ end free energies are computed. “Left” and “right” refer to the order of the two primers and say nothing about their role (sense or antisense).

metricdefinition
end_left-right_dgΔG (kcal/mol) for the 3′ end of the left primer annealed to the right primer
end_right-left_dgΔG (kcal/mol) for the 3′ end of the right primer annealed to the left primer
min_end_heterominimum of both: the heterodimer risk metric used for classification
end_left-left_dgΔG (kcal/mol) for the 3′ end of the left primer annealed to itself
end_right-right_dgΔG (kcal/mol) for the 3′ end of the right primer annealed to itself
min_end_homominimum of both self-dimer values

The direction with the lower ΔG is the dominant direction; its alignment is shown first. Classification uses min_end_hetero only.

⚠ homodimer predictions are not validated. In the training data, the no-template control (NTC) signal cannot tell homodimers from heterodimers, and predicted homodimers had no predictive value:

  • min_end_homo gave an AUC of 0.60, against 0.94 for min_end_hetero, and added nothing to min_end_hetero in a logistic model (p = 0.30)
  • 7 of the 100 clean pairs had a strong predicted homodimer (below −2.44 kcal/mol, down to −6.46 kcal/mol) without any NTC signal

Homodimer values (end_left-left_dg, end_right-right_dg, min_end_homo and homodimer rows) are reported for completeness only. Interpret them with caution.

calibration and risk tiers

The model was calibrated on 200 RT-qPCR reactions (100 confirmed dimers, 100 clean pairs; data courtesy of Biogazelle): 250 nM of each primer, SsoAdvanced Universal SYBR Green Supermix, 45 cycles, 60 °C annealing, evaluated in no-template control (NTC) reactions. A positive NTC signal defined a dimer. Area under the ROC curve: 0.939.

alignments

Each entry shows the dominant direction first, then the other direction (one diagram for homodimers):

5'-[top strand, 5'→3']-3' [match string] 3'-[bottom strand, 3'→5' left to right]-5'

| is a Watson–Crick pair; . on a strand is a bulge (a nucleotide looping out opposite the other strand); . in the match string is a paired mismatch. Example (ΔG = −2.65 kcal/mol, high risk), with a bulged T on the top strand:

5'-CTCTATGTGTTGGAGTCAT.GAAG-3' ||| | |||| 3'- TTACTCGGAGTCTTCCTTAC-5'

The diagram is the structure primer3 used to compute the reported ΔG, including bulges and internal loops.

input and output

pair mode

  • four columns: left ID left sequence right ID right sequence; IDs are optional
  • recognized column names (case-insensitive) include forward_primer_name, forward_primer, reverse_primer_name, reverse_primer and outcome

multiplex mode

  • one primer per row: ID and sequence, or the sequence only (IDs P001, P002, … are generated)
  • recognized column names include primer_name, primer_id, name, id, primer_seq, sequence and seq
  • N primers give N × (N − 1) / 2 heterodimers plus N homodimers

general

  • separators: tab, comma or semicolon; files: .xlsx, .csv, .tsv, .txt; lines starting with # are ignored
  • sequences may contain A, C, G and T only (case-insensitive)
  • downloads: the results table (.xlsx, .tsv, .csv) and the alignment report (.txt) have the same layout as the Python script output
  • every output file states the DimerDetective version and build, for example 1.2 (build 20261102-0058): in the header of the alignment report and in a final version column of the tables. The build is the date and time (Belgian time) of the last change; the version (1.2) is the one to cite.
